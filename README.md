# Port-Scanner-Lite 🛡️

A lightweight, beginner-friendly TCP port scanner written in Python for offensive security reconnaissance and network auditing.

## Features
* Scans standard ports (1 through 1024).
* Fast socket-based connection testing with timeout error handling.
* Simple command-line interface.

## Usage
Run the script using Python 3 by passing the target IP address or domain as an argument:

```bash
python3 scanner.py 127.0.0.1
